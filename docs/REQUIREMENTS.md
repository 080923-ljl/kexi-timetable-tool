# 需求与验收标准

## 需求 1：读入课表

### 功能

- 支持手动录入课程名、星期几、开始时间和结束时间。
- 支持从 CSV 导入相同字段。
- 页面生成「本周课表」的文本视图。
- 同一课程连续节次在课间容差内合并显示。

### 验收

- 中文表头和英文表头都可以识别。
- CSV 中带引号的课程名可以正常解析。
- `09:00-09:45`、`09:55-10:40` 这类同课程连续节次显示为合并块。

## 需求 2：算空闲时段

### 功能

- 每位成员可以分别设置一周七天的可用时间范围。
- 从每日可用范围中扣除课程，得到连续空闲时段。
- 支持同一课程合并容差和最短空闲时长。
- 展示本周空闲总量、最长连续空闲、可用天数和课程条目数。

### 验收

- 未启用的日期不参与计算。
- 课程时间会从每日可用范围中扣除。
- 小于最短空闲时长的碎片不会进入结果。

## 需求 3：找共同空闲时间

### 功能

- 支持选择至少两位成员。
- 计算所有成员课表和每日可用范围的交集。
- 结果按持续时间从长到短排序。

### 验收

- 只选择一位成员时提示至少选择两位。
- 共同空闲不考虑任何成员已有课程或不可用时间。
- 同等长度时按星期和时间先后排序。
