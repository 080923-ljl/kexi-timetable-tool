# 文件说明

## 页面入口

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构，包含三个需求对应的标签页。 |
| `styles.css` | 页面样式、响应式布局和打印友善的文本视图样式。 |
| `app.js` | 页面交互、成员管理、CSV 文件读取和本地存储。 |
| `logic.js` | 与界面无关的纯计算逻辑，供页面和测试共同使用。 |

## 数据与测试

| 文件 | 说明 |
| --- | --- |
| `sample-timetable.csv` | CSV 导入示例。 |
| `tests/logic.test.js` | Node.js 内置测试，覆盖三个需求的主要计算路径。 |
| `README.md` | 项目总览、运行方式、CSV 格式和功能说明。 |

## GitHub 配套

| 文件 | 说明 |
| --- | --- |
| `.github/PULL_REQUEST_TEMPLATE.md` | 创建 PR 时自动带出的检查清单。 |
| `CONTRIBUTING.md` | 分支、提交和测试约定。 |
| `docs/REQUIREMENTS.md` | 需求拆解和验收标准。 |
