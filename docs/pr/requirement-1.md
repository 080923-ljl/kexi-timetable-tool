# 需求 1：读入课表

## 对应功能

- 手动录入课程名、星期几、开始时间和结束时间。
- CSV 导入与字段自动识别。
- 本周课表文本视图。
- 同一课程连续节次的合并展示。

## 实现位置

- `index.html`：录入表单、CSV 导入区和文本视图。
- `app.js`：表单交互、文件读取和成员课表管理。
- `logic.js`：CSV 解析、星期和时间解析、课程合并。

## 验证

```powershell
node --test tests/requirement-1.test.js
```

独立测试覆盖中文 CSV 表头、带引号课程名、连续课程合并和文本视图。
