# 课隙

一个从课表计算空闲时间的纯前端小工具。支持手动录入、CSV 导入、每日空闲计算，以及多人共同空闲时间筛选。

## 直接运行

不需要安装依赖或启动服务，直接打开根目录下的 `index.html` 即可。

## 功能

### 需求 1：读入课表

- 支持手动录入：课程名、星期几、开始时间、结束时间。
- 支持 CSV 导入，自动识别中英文字段名。
- CSV 支持带引号的课程名，例如 `"高等数学, A班"`。
- 页面实时生成「本周课表」的文本视图。
- 同一课程连续两节在课间容差内会合并显示，避免出现 `09:00-09:45`、`09:55-10:40` 两个碎片。

### 需求 2：算空闲时段

- 每位成员分别设置每天的可用时间范围。
- 默认可用时间为周一至周五 `08:00-22:00`。
- 从每日可用范围中扣除课程，得到连续空闲时段。
- 可设置同一课程合并容差和最短空闲时长。
- 展示本周总空闲、最长连续空闲、可用天数和课程条目数。

### 需求 3：找共同空闲时间

- 选择至少两位成员，计算所有人的空闲时间交集。
- 同步考虑每位成员各自的每日可用范围和课表。
- 结果按持续时间从长到短排列。
- 同等长度时，按星期和时间先后排列。

## CSV 格式

```csv
课程名,星期几,开始时间,结束时间
高等数学,星期二,09:00,09:45
高等数学,星期二,09:55,10:40
数据结构,星期一,14:00,15:35
```

可下载页面内模板，也可以直接使用仓库中的 `sample-timetable.csv`。

支持以下字段别名：

- 课程名：`课程名称`、`科目`、`courseName`、`subject`
- 星期几：`星期`、`周几`、`weekday`、`week`
- 开始时间：`开始`、`startTime`、`begin`
- 结束时间：`结束`、`endTime`、`finish`

## 计算规则

- 时间统一转换为分钟后再计算，避免字符串比较。
- 同一课程在设定容差内会合并为一个时间块。
- 空闲时段是每日可用范围扣除课程时间后的结果。
- 多人共同空闲是对各成员空闲区间逐项求交集。
- 所有数据只保存在浏览器 `localStorage`，不会上传。

## 测试

项目使用 Node.js 内置测试运行器，无第三方依赖：

```powershell
node --test tests/logic.test.js
```

测试覆盖：

- 中文和英文 CSV 表头解析
- 星期和 AM/PM 时间解析
- 连续课程合并
- 每日空闲时段计算
- 多人共同空闲交集与排序
- 本周课表文本生成

## 对应三次 PR 的建议拆分

如果需要在 GitHub 上按作业要求提交三次 PR，可以使用以下分支和变更范围：

1. `feature/requirement-1-timetable-input`：课程录入、CSV 导入、本周课表文本视图。
2. `feature/requirement-2-free-time`：每日可用范围、空闲计算、连续课程合并设置。
3. `feature/requirement-3-common-free`：多人选择、共同空闲交集、按长度排序。

最终分支合并后即为当前实现。
